# Voice Atelier project

Independent local voice-cloning and TTS studio. Do not modify DSH or global machine settings. Read SPEC.md API contract. Russian and English UI. All runtime/models/user files in project data/ (or explicit VOICE_ATELIER_HOME). Never commit recordings, credentials, models or generated user audio. Never use cloud synthesis/LLM or download models implicitly. Base cloning does NOT support free-form instruction; VoiceDesign makes a new identity. No silent/fake production synthesis. Respect rights and consent. Run `.venv/Scripts/python.exe -m pytest tests -q`; production API tests use injected adapters only. Real audio quality claims require a real measured GPU synthesis and audition; mocks do not establish it. Document untested cases. Model changes must pin revision, verify safetensors/hash, preserve 8GB serial scheduling and offline inference. Windows Setup must stay project-local, no admin/PATH/registry changes.
