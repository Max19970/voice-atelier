### Реальный GPU-синтез

Первый полный прогон: **11 PASS, 0 FAIL, 0 BLOCKED**, один SKIP означал пропуск повторного скачивания уже установленной модели.

| Этап | Длительность аудио | Время задания |
|---|---:|---:|
| Новый синтетический эталон VoiceDesign | 6,00 с | 42,31 с |
| Две новые русские реплики Base с этим эталоном | 4,64 + 5,12 с | 85,88 с на обе |
| WAV и ZIP, пауза 300 мс | 10,06 с микса | 6,30 с на оба экспорта |

Время включает загрузку/переключение моделей и опрос очереди, не является чистым RTF и не обещает такую же скорость на другом ПК. PCM16 mono 24 кГц декодируется; проверены длительности, ненулевая амплитуда, контрольные суммы, порядок/пауза, ZIP-манифест и сохранение проекта после перезапуска. Пиковая VRAM не измерялась.

Позднее выполнен парный A/B языка описания VoiceDesign на одном русском тексте, seed 42/43: английское описание дало более низкую F0, оба результата при ручном прослушивании соответствовали запросу низкого взрослого мужского голоса. Это два образца, не общий тест естественности, возраста или сходства. [Подробности исправления](<docs/voice-design-direction-fix.md>).

## Воспроизведение

Установить проект через [Setup.cmd](<Setup.cmd>), затем:

```powershell
# Unit/API, RU/EN, JavaScript; Node нужен для JS-проверок
.\Verify.ps1 -TestsOnly

# Полная проверка: сначала остановить свою запущенную студию на 8765.
# Явное разрешение скачивания двух моделей около 9 ГБ:
.\Verify.ps1 -DownloadApproved
```

Полная проверка запускает собственный сервер и не присоединяется молча к занятым портам. Для браузерной части нужен установленный Microsoft Edge; драйвер Playwright ставится локально, отдельный браузер не скачивается. Отчёты и синтетические тестовые результаты создаются локально и исключены из Git.

## Что не установлено этой проверкой

- Нет независимого WER/SIM-бенчмарка, доказательства «лучшего движка» или гарантии качества любого человеческого клона. Первоначальный smoke использовал искусственный эталон, не персональную запись.
- Не проверены микрофон/разрешения MediaRecorder на разном оборудовании, многочасовые сценарии, все языки, CPU, 0.6B, fine-tuning, квантование, другие ОС/браузеры.
- Base не принимает свободную эмоциональную инструкцию; VoiceDesign создаёт **новую** личность. Для переиспользования удачного голоса сохраните эталон и клонируйте его Base.
- Темп — FFmpeg atempo; паузы — тишина; нормализация — по пику, не EBU R128. Seed — best effort, не гарантия побитовой повторяемости; отмена кооперативная.
- Записи/база не шифруются приложением. Отметка согласия фиксирует заявление пользователя, не юридическую проверку. Не используйте синтез для обмана или выдачи за подлинную запись.
