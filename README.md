# Voice Atelier

Локальная студия клонирования голосов и озвучки на Windows. Русский / English, библиотека голосов, многоголосые сценарии, несколько дублей, создание нового голоса по описанию, экспорт WAV и ZIP с метаданными. Без облачного TTS, подписки и отправки записей на серверы.

**Целевая конфигурация:** NVIDIA RTX 3060 Ti 8 ГБ, 32 ГБ ОЗУ. Скорость и качество реального синтеза нельзя вывести из характеристик: результаты проверки фиксируются отдельно в [VERIFICATION.md](<VERIFICATION.md>).

## Возможности

- Локальное zero-shot клонирование по записи и точной расшифровке.
- Новый голос по текстовому описанию, сохранение эталонов в библиотеку.
- Многоголосые проекты, автосохранение, несколько дублей и отметки устаревших результатов.
- Последовательная GPU-очередь, отмена заданий, темп и паузы, экспорт WAV/ZIP.
- RU/EN интерфейс, portable-установка без администратора, loopback API.

Репозиторий содержит **исходники, а не установленные модели или голосовые записи**. Движок, веса и пользовательская библиотека создаются локально после установки. Проверено на RTX 3060 Ti: **62 автотеста, 12 общих браузерных проверок и реальный GPU-дизайн → клонирование → WAV/ZIP**; границы проверки — в [отчёте](<VERIFICATION.md>).

## Быстрый старт

Склонируйте репозиторий или скачайте ZIP исходников и распакуйте его в постоянный каталог. Требуются Windows x64, интернет для установки, актуальный драйвер NVIDIA и свободное место для Python/PyTorch и моделей (примерно 9 ГБ только для двух моделей 1.7B).

1. Дважды щёлкните [Setup.cmd](<Setup.cmd>). Он скачивает portable Python 3.11, PyTorch CUDA и зависимости **внутрь проекта**, без прав администратора и изменения системного PATH. Интернет нужен, загрузка может занять время и несколько ГБ. Веса моделей на этом шаге **не скачиваются**.
2. Дважды щёлкните [Start.cmd](<Start.cmd>). Студия откроется на **http://127.0.0.1:8765**. Не закрывайте консоль во время работы; Ctrl+C останавливает сервер.
3. Во вкладке **Модели** скачайте Qwen3-TTS **1.7B Base** (~4,5 ГБ) для качества или **0.6B Base** (~2,5 ГБ) для большего запаса видеопамяти. При нехватке памяти выгрузите модель и закройте другие GPU-приложения; не держите обе модели одновременно.
4. Во вкладке **Голоса** загрузите чистый образец своего голоса или голоса, на использование которого у вас есть разрешение. Впишите **дословную расшифровку выбранного участка** и подтвердите основание использования.
5. В **Студии** создайте проект, разбейте сценарий на реплики, выберите диктора для каждой, сгенерируйте и прослушайте дубли. Экспортируйте выбранные дубли в WAV или ZIP.

Для генерации **новой личности голоса по описанию**, а не изменения личности клона: скачайте **1.7B VoiceDesign** (~4,5 ГБ) и откройте **Дизайн голоса**. Полученный голос можно сохранить как новый эталон в библиотеку. Текст одного вызова VoiceDesign ограничен **240 символами**, чтобы модель не создавала независимые личности на разных фрагментах. Для длинной озвучки сначала сохраните эталон, затем используйте Base-клонирование. Имя голоса и расшифровку можно исправить кнопкой редактирования; изменение расшифровки помечает прежние дубли устаревшими.

**Пресеты VoiceDesign и язык озвучки — разные вещи.** Пресет подставляет описание голоса **по-английски**, а язык произносимого текста выбирается отдельно и может оставаться русским. После обновления нажмите **Ctrl+F5** и выберите пресет заново — иначе браузер может взять старый файл. Автоматического перевода вашего описания в приложении нет: своё описание лучше писать по-английски. Подробнее: [исправление управления пресетами](<docs/voice-design-direction-fix.md>).

## Что действительно управляется

| Возможность | Как работает |
|---|---|
| Клонирование тембра | Qwen Base по аудиоэталону и его точной расшифровке |
| Голос по свободному описанию | Qwen VoiceDesign: возраст, тембр, манера речи, эмоциональная подача; это **новый голос**, не исходный клон |
| Манера существующего клона | Выбор другого аудиоэталона того же диктора с нужной подачей; перенос не гарантирован |
| Скорость | Постобработка FFmpeg `atempo`, без намеренного изменения высоты тона; не «эмоция модели» |
| Паузы | Вставка цифровой тишины между репликами при сборке |
| Вариативность | Несколько дублей и seed; побитовая воспроизводимость CUDA не гарантируется |
| Длинные тексты | Поочерёдная генерация коротких фрагментов, экономия VRAM; стыки нужно прослушать |

**Критично:** `generate_voice_clone` у Qwen Base не поддерживает свободный `instruct`. Теги `[шёпот]` в тексте не превращаются в команду и могут быть произнесены. Студия не делает вид, что «прошепчи тем же голосом» работает через скрытый промпт. VoiceDesign не сохраняет личность загруженного человека. Полноценное клонирование с произвольными эмоциями требует отдельного совместимого движка; текущая версия не обещает его возможности.

## Как получить лучший результат

- Сухая речь без музыки, эха и других говорящих. Обычно полезнее 6–20 секунд хорошей записи, чем минута шумной. Выбранный эталон: 2–30 секунд.
- WAV/FLAC предпочтительнее сжатого мессенджером аудио. Пересохранение плохой записи в WAV не восстанавливает качество.
- Не срезайте начала/концы слов. Расшифровка относится **к обрезанному**, а не исходному длинному файлу. Автоматическая транскрипция в этой версии не выполняется.
- Для русского используйте «ё», развёрнутые сокращения и числа словами там, где важна конкретная форма. Проверяйте ударения и имена. Комбинируемый знак ударения не гарантирует нужное произношение в базовом чекпоинте.
- Делайте отдельные эталоны одного диктора: нейтральный, спокойный, эмоциональный. Называйте их явно. Это референсы, а не гарантированный ползунок эмоции.
- Сначала короткая тестовая фраза, затем длинный сценарий. Слушайте каждый дубль; нет объективной кнопки «максимальное сходство».
- Нормализация пика в экспорте — не шумоподавление, не восстановление качества и не мастеринг по EBU R128.

## Данные и приватность

Записи, модели, база проектов и результаты находятся в `data/` внутри проекта. **Эта папка содержит чувствительные биометрические данные**: ограничьте доступ и резервируйте её самостоятельно. Экспорт ZIP содержит текст сценария и сведения об эталоне/разрешении; проверяйте содержимое перед передачей другим людям.

Сервер слушает только loopback. API требует токен текущего запуска; интерфейс не использует CDN. Сеть нужна при установке зависимостей и по явной команде скачивания модели. Для запрета скачивания моделей запустите:

```powershell
.\Start.ps1 -Offline
```

Облачная озвучка, внешние LLM, отправка референсов и телеметрия приложением не предусмотрены. Это не защита от других программ с доступом к вашим файлам и не криптографическое хранилище. Подтверждение прав в интерфейсе фиксирует ваше заявление, но не проверяет юридическое согласие. Не используйте голоса для обмана, мошенничества или выдачи синтетической речи за запись человека.

## Установка и диагностика

```powershell
# Только интерфейс/API и тесты, без большого движка
.\Setup.ps1 -RuntimeOnly

# Полная установка для NVIDIA (CUDA 12.6 runtime внутри PyTorch)
.\Setup.ps1

# CPU-версия (очень медленная; не рекомендуется для этой видеокарты)
.\Setup.ps1 -CpuOnly
.\Start.ps1 -Device cpu

# Другой порт / без автоматического открытия браузера
.\Start.ps1 -Port 8766 -NoBrowser

# Тесты — не являются доказательством качества реального синтеза
.\.venv\Scripts\python.exe -m pytest tests -q
```

Не запускайте Setup от администратора. Системный CUDA Toolkit и FlashAttention не требуются; используется PyTorch SDPA. Интернет, свободное место и драйвер NVIDIA всё равно необходимы. Перенос каталога после создания `.venv` может потребовать пересоздания локального окружения; резервируйте `data/`, не удаляйте её ради ремонта Python.

Отмена генерации кооперативная: обычно между фрагментами, а не мгновенное прерывание текущего CUDA-вызова. После аварийного закрытия незавершённые задания должны помечаться ошибкой; готовые дубли сохраняются. При ошибке нехватки VRAM начните с 0.6B и короткой реплики.

## English quick start

Run [Setup.cmd](<Setup.cmd>) once, then [Start.cmd](<Start.cmd>). Open http://127.0.0.1:8765 and select EN. Download a model explicitly in Models, add a clean consented reference with an exact transcript, create a multi-speaker script, generate and audition takes, then export WAV/ZIP. Everything is processed locally; installation/model downloads require internet.

Qwen Base clones voices but **does not accept free-form emotional instructions**. VoiceDesign follows a description but creates a **new identity**. VoiceDesign presets insert an **English** description, while the spoken language is chosen separately and may stay Russian: press **Ctrl+F5** and re-apply the preset after updating, and note there is no built-in translation of your own description — write it in English. Details: [voice design direction fix](<docs/voice-design-direction-fix.md>). Rate is labeled FFmpeg postprocessing, pauses are digital silence. Do not use generated audio for deceptive impersonation. See [VERIFICATION.md](<VERIFICATION.md>) for what was actually run and what remains unverified.
